## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (ex.: `climax`), público.
2. Clique em **Add file → Upload files** e arraste **todo o conteúdo desta pasta** (`index.html`, a pasta `img` e o arquivo `.nojekyll`). Depois, **Commit changes**.
3. Vá em **Settings → Pages**. Em *Source*, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e clique em **Save**.
4. Em 1 ou 2 minutos o site fica no ar em `https://SEU-USUARIO.github.io/climax/`.

## Domínio próprio (opcional)

Em **Settings → Pages → Custom domain**, coloque o domínio (ex.: `climaxrefrigeracao.com.br`) e siga as instruções de DNS do GitHub.
